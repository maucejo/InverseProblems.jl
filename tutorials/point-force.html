Localizing a point force

This tutorial reconstructs a harmonic point force acting on a simply supported beam from noisy acceleration measurements. It compares the classical Tikhonov regularization with sparsity-promoting priors, and shows how the regularization parameter is chosen.

single frequencyAdditiveMultiplicativeBayesian

The forward model

The synthetic data are generated with StructuralVibration.jl, which provides the beam models, their modal bases, the transfer functions and the measurement noise. Both packages export a function named solve: StructuralVibration is therefore imported as SV, and its solver is called SV.solve.

import StructuralVibration as SV
using StructuralVibration: Beam, ModalFRFProblem, modefreq, modeshape, agwn

The structure is a simply supported steel beam of length ℓ=1 m with a rectangular cross-section (30×10 mm). Its natural frequencies and mass-normalized mode shapes are computed up to 5 kHz, at the 40 sensors and at the 31 reconstruction points:

L, b, h = 1.0, 0.03, 0.01
beam = Beam(L, b * h, b * h^3 / 12, 2.1e11, 7850.)   # L, S, I, E, ρ
ωn, kn = modefreq(beam, 5000.)                        # natural frequencies (rad/s), wavenumbers

xm = grid(40)                                         # sensor positions
xr = grid(31)                                         # reconstruction points
ϕm = modeshape(beam, kn, xm)
ϕr = modeshape(beam, kn, xr)
@printf "%d modes below 5 kHz, first natural frequencies (Hz): %s\n" length(ωn) string(round.(ωn[1:6] / 2π, digits = 1))

14 modes below 5 kHz, first natural frequencies (Hz): [23.5, 93.8, 211.1, 375.3, 586.3, 844.3]

The FRF matrix is the modal sum

computed by ModalFRFProblem with a modal damping ratio 𝜉=1%. We excite the beam between its 5th and 6th natural frequencies; type = :acc returns accelerances.

f0 = (ωn[5] + ωn[6]) / 4π                             # excitation frequency (Hz)
@printf "Excitation frequency: %.0f Hz\n" f0

prob_frf = ModalFRFProblem(ωn, 0.01, f0:f0, ϕm, ϕr)
H = SV.solve(prob_frf; type = :acc, progress = false).u[:, :, 1];   # 40 × 31

Excitation frequency: 715 Hz

The reference force is a unit point force at the 9th reconstruction point. The measurements are polluted by a complex Gaussian white noise with a signal-to-noise ratio of 26 dB, added by agwn.

uref = zeros(ComplexF64, length(xr))
uref[9] = 1.0
y = agwn(H * uref, 26)
prob = InverseProblem(H, y)

InverseProblem(40 data, unknown 31×1, DenseOperator)

Even with more sensors than unknowns, the problem is ill-posed. The matrix 𝐻 is a sum of modal contributions, so its rank cannot exceed the number of modes retained (14 here): beyond the 14th singular value, the singular values drop to the numerical zero, and the smaller ones before it amplify the measurement noise.

s = svdvals(H)
fig = Figure(size = (820, 260))
ax = Axis(fig[1, 1], yscale = log10, xlabel = "Index", ylabel = "Singular value",
          title = @sprintf("Rank: %d, numerical condition number: %.1e", count(>(1e-10 * s[1]), s), s[1] / s[end]))
scatterlines!(ax, s)
fig

Tikhonov regularization

The additive formulation minimizes ‖𝑦−𝐻𝑢‖22+𝜆𝑅(𝑢). With Lq(2.0), 𝑅(𝑢)=‖𝑢‖22: this is the Tikhonov regularization. The regularization parameter 𝜆 is selected by a rule.

rules = (LCurve(), GCV(), BayesEstimator())
tik = [solve(prob, Additive(Lq(2.0); λ = r)) for r in rules]
[(nameof(typeof(r)), s.λ) for (r, s) in zip(rules, tik)]

3-element Vector{Tuple{Symbol, Float64}}:
 (:LCurve, 105.68594315547529)
 (:GCV, 0.9241851629257677)
 (:BayesEstimator, 0.5254764650922371)
fig = Figure(size = (820, 300))
ax = Axis(fig[1, 1], xlabel = "Position x (m)", ylabel = "|u| (N)")
scatterlines!(ax, xr, abs.(uref), color = FG, linestyle = :dash, label = "Reference")
for (r, s) in zip(rules, tik)
    scatterlines!(ax, xr, abs.(s.u), label = string(nameof(typeof(r))))
end
axislegend(ax, position = :rt)
fig

The force is correctly localized, but its amplitude is underestimated and it leaks onto the neighbouring points: the ℓ2 norm favors distributed fields.

Sparsity-promoting priors

A point force is a sparse field. The ℓ𝑞 (quasi-)norm with 𝑞≤1 promotes such solutions. Because the regularization term is no longer quadratic, the problem is solved by the iteratively reweighted (IR) algorithm.

sparse_cases = [
    "Additive ℓ1 (GCV)"  => Additive(Lq(1.0); λ = GCV()),
    "Multiplicative ℓ1"  => Multiplicative(Lq(1.0)),
    "Multiplicative ℓ0.5" => Multiplicative(Lq(0.5)),
    "Bayesian (q estimated)" => Bayesian(Lq(1.0)),
]
sols = [name => solve(prob, f) for (name, f) in sparse_cases];

fig = Figure(size = (820, 340))
ax = Axis(fig[1, 1], xlabel = "Position x (m)", ylabel = "|u| (N)")
scatterlines!(ax, xr, abs.(uref), color = FG, linestyle = :dash, label = "Reference")
for (name, s) in sols
    scatterlines!(ax, xr, abs.(s.u), label = name)
end
axislegend(ax, position = :rt)
fig

The multiplicative formulation minimizes ‖𝑦−𝐻𝑢‖22⋅𝑅(𝑢): the regularization parameter is updated automatically at each iteration, so that nothing has to be tuned. The Bayesian formulation goes further and estimates the noise precision 𝜏𝑛, the prior precision 𝜏𝑠 and the shape parameter 𝑞 of the prior from the data:

bayes = last(sols[end])
bayes.hyper

(τn = 64.52592773516061, τs = [54.777223987031846], q = [0.061138674762994255])

The estimated shape parameter is close to the lower bound of its search interval (shape_bounds = (0.05, 2.0)): the data are best explained by a very sparse field.

Tip

The choice between formulations is mostly a matter of prior knowledge:

  • use Additive when you want to control 𝜆 (or choose it with a well-known rule);
  • use Multiplicative for a parameter-free reconstruction with a fixed prior shape;
  • use Bayesian when the shape of the prior is unknown, or when you need a consistent estimate of the noise level and posterior uncertainties.
